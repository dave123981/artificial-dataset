Installation
============

Requirements
------------

* Python 3.12 or later
* PyTorch 2.12 or later

From PyPI
---------

.. code-block:: bash

   pip install artificial-dataset

From source
-----------

Clone the repository and install in editable mode:

.. code-block:: bash

   git clone https://github.com/dcintlab/artificial-dataset.git
   cd artificial-dataset
   pip install -e .
